# AngelBridge｜天使桥 UX 静态交互原型

本分支提供一个以手机 App 形式呈现的静态 H5 原型。页面结构和视觉语言参考当前 Ardot UI 设计稿，灵宠使用项目已有的 12 生肖素材。

## 范围

- 首页与 7 个频道：热门、视频、经验、闲置、找工作、找物、找人
- 内容详情与可解释匹配信息
- 发起连接确认、待回应消息和人生树成长反馈
- 12 生肖灵宠选择与本地保存
- 静态创建、个人中心和基础反馈状态

本原型不包含后端、数据库或真实消息发送。交互数据仅保存在当前浏览器的 `localStorage` 中，存储键为 `angel-bridge-prototype-v1`。

## 本地运行

```bash
npm run serve
```

访问 `http://127.0.0.1:4173/`。

## 自动测试

```bash
npm test
```

## 推荐演示路径

1. 首页切换到“找工作”频道。
2. 打开“AI 产品体验设计师”。
3. 查看匹配理由并发起连接。
4. 在“消息”中查看“待回应”状态。
5. 进入“我”→“人生树”，查看成长值和待确认事项变化。

## 分支

实现位于 `feat/ux-static-mobile-prototype`，不修改后端和数据库相关工作。
